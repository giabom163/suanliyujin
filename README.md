# 算力余烬

《算力余烬》（Ember of Compute）是一款以断网后的算力封锁区为背景的 4v1 非对称生存对抗游戏。四名火种运维员潜入废弃设施，搬运显卡、修复算力节点、打开逃生门。一名稽核员负责巡检、追击和封锁撤离路线。

> 向着余烬，重启黎明。

- **在线试玩**：[giabom.online](https://giabom.online/)
- **游戏设定**：[世界观](世界观.md)
- **AI 调试**：[EmberAI 测试提示词](https://giabom.online/ai-interface)

## 怎么玩

- **运维员**：搬卡、装卡、修机。被追击时借隔离门和掩体牵制，队友被送进回收舱时设法救援。修好四台节点后全场通电，启动逃生门并穿过撤离通道。
- **稽核员**：追击运维员，将倒地者送进回收舱。根据节点进度，在继续追击、守舱和封锁终端之间取舍。
- **管理员观战**：开局后可看全图和角色状态。网页的 EmberAI 接口支持读取观测、给运维员分派当前可用任务，以及调用支持的攻击和技能。
